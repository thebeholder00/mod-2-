# Skin Shift (Forge 1.21.1)

Клавиша **V** (меняется в Настройки → Управление → Skin Shift):
руки поднимаются к груди → вокруг игрока крутится вихрь жёлтых частиц → скин попиксельно «проявляется» на новый.
Повторное нажатие — то же самое, но скин возвращается.

## Как получить .jar через GitHub
1. Создай пустой репозиторий на GitHub.
2. Загрузи в него **содержимое** этой папки (чтобы `build.gradle` и папка `.github` лежали в корне репозитория).
   Важно: папка `.github` скрытая — при загрузке через сайт перетащи её тоже.
3. Открой вкладку **Actions** → workflow **Build mod** запустится сам (или нажми *Run workflow*).
4. После зелёной галочки внутри запуска внизу в разделе **Artifacts** скачай `skinshift-jar` — там `skinshift-1.0.0.jar`.
   Если красный крестик — открой лог шага **Build** и пришли текст ошибки мне.

## Свои скины
* `src/main/resources/assets/skinshift/textures/skin/new_skin.png` — новый скин (сейчас твой).
* `src/main/resources/assets/skinshift/textures/skin/old_skin.png` — запасной «старый» скин.
  По умолчанию «старым» считается НАСТОЯЩИЙ скин игрока (считывается автоматически), а old_skin.png
  используется только если считать не получилось. Чтобы всегда брать old_skin.png, поставь
  `USE_REAL_SKIN_AS_OLD = false` в `client/ClientFx.java`.
Оба файла — PNG 64x64. Замени файлы по тем же путям и пересобери.
